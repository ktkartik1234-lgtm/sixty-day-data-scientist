## The skeleton

Adapt the column names to your CSV; the shape of the script is the lesson.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats

df = pd.read_csv("data/financial_stress.csv")

# 1. clean — day 1 habits
df = df.dropna(subset=["monthly_income", "stress_level"])
df = df[df["monthly_income"] > 0]
print("kept", df.shape[0], "rows of", df.shape[1], "columns")

# 2. describe
print(df[["monthly_income", "stress_level"]].describe().T)

# 3. visualize — two views, one figure
fig, axes = plt.subplots(1, 2, figsize=(11, 4))
axes[0].hist(df["monthly_income"], bins=40)
axes[0].set_title("Income distribution")
axes[1].scatter(df["monthly_income"], df["stress_level"], alpha=0.2, s=8)
axes[1].set_title("Income vs stress")
plt.savefig("day10_overview.png", dpi=120, bbox_inches="tight")

# 4. one hypothesis test, declared in advance: does stress differ
# between the lower and upper income halves? — day 8's Welch test
median_income = df["monthly_income"].median()
low  = df.loc[df["monthly_income"] <= median_income, "stress_level"]
high = df.loc[df["monthly_income"] >  median_income, "stress_level"]
t, p = stats.ttest_ind(low, high, equal_var=False)
se = np.sqrt(low.var() / len(low) + high.var() / len(high))   # day 6
print(f"gap = {high.mean() - low.mean():.3f}, SE = {se:.3f}, t = {t:.2f}, p = {p:.2e}")
```

## From p-value to finding

A test result becomes a finding only after two honest checks. **Size**: with
50,000 rows almost any gap is "significant" — report the gap and its standard
error, not just the p-value. **Words**: each bullet must survive being read
by someone who will never open the notebook. "High-income respondents score
1.2 points lower on stress (SE 0.1); the gap is unlikely to be chance
(p near 0), but income explains little of the variation overall."
