You can now ship a model and track its birth. The uncomfortable truth is what
happens next: models rot while dashboards stay green. Today you build the
alarms — and tomorrow the capstone begins, so these habits go straight to
work.

## 1. Two ways a model decays

Remember random variables from the probability track: a model is fit on
samples drawn from a distribution, and deployment does not freeze that
distribution. Two distinct failures follow:

- **Data drift** — the inputs $P(X)$ shift while the relationship
  $P(Y \mid X)$ holds. A recession moves the income distribution; the meaning
  of the features is unchanged. Detectable *without labels*.
- **Concept drift** — the relationship $P(Y \mid X)$ itself changes. Same
  incomes, but a new government program redefines what stress looks like.
  Needs labels, so it is found late.

Both silently void the i.i.d. assumption your validation set stood on.

## 2. Detecting drift: KS test and PSI

The two-sample Kolmogorov-Smirnov statistic compares the empirical CDFs of
train and serving data:

$$D_{KS} = \sup_x \left\lvert F_{\text{train}}(x) - F_{\text{serve}}(x) \right\rvert$$

$D_{KS}$ is itself a random variable: under the null hypothesis that both
samples share a distribution, the test's p-value tells you how surprising the
observed gap is. PSI buckets both distributions into $B$ bins and sums:

$$\mathrm{PSI} = \sum_{i=1}^{B} (p_i - q_i)\,\ln\!\frac{p_i}{q_i}$$

with $p_i$ and $q_i$ the population shares of bin $i$ in train and serving
data. Rule of thumb: below 0.1 is quiet, 0.1 to 0.25 is watch, above 0.25 is
act.

```python
import numpy as np
from scipy import stats

def psi(expected: np.ndarray, actual: np.ndarray, bins: int = 10) -> float:
    edges = np.quantile(expected, np.linspace(0, 1, bins + 1))
    edges[0], edges[-1] = -np.inf, np.inf              # open-ended tails
    e = np.histogram(expected, edges)[0] / len(expected)
    a = np.histogram(actual, edges)[0] / len(actual)
    e, a = np.clip(e, 1e-6, None), np.clip(a, 1e-6, None)   # avoid log(0)
    return float(np.sum((a - e) * np.log(a / e)))

for col in NUMERIC_FEATURES:
    ks = stats.ks_2samp(train[col], serve[col])
    score = psi(train[col], serve[col])
    if ks.pvalue < 0.01 or score > 0.25:
        print(f"DRIFT {col}: KS p-value {ks.pvalue:.4f}, PSI {score:.3f}")
```

## 3. Serving metrics: the system and the output

Two dashboards, both mandatory. **System health**: latency p50 and p95, error
rate, throughput — the Day-51 and Day-52 work, watched in production.
**Model health without labels**: the prediction distribution itself. Log
every prediction; if the mean predicted probability jumps from 0.20 to 0.50
overnight, either the world changed or an upstream pipeline did — both are
pages. Often this output shift is your first and only label-free alarm.

## 4. Shadow deployment and retraining triggers

Never promote a candidate on offline metrics alone. A **shadow deployment**
mirrors live traffic to the candidate model, logs its predictions, and serves
nothing to users; when labels arrive you compare both models on the same real
outcomes and promote with evidence. Then write the triggers down as policy,
because "we will keep an eye on it" is not a policy:

- PSI above 0.25 on two consecutive windows — investigate before retraining.
- Relative PR-AUC drop above 10 percent once labels land — retrain.
- Calendar-based refresh every quarter regardless.
- Always first: rule out an upstream bug — a renamed column looks exactly
  like drift.

<Callout kind="deep" title="Why silent decay is the industry default">
  Software fails loudly — exceptions, 500s, stack traces. Models fail
  politely: the API returns 200 with confidently wrong numbers, uptime stays
  perfect and every dashboard is green. Ground truth arrives weeks late
  (defaults materialize, stress surveys come in quarterly), so nothing
  compares predictions to reality in real time — decay is silent *by
  construction*, not by negligence. Drift monitors, prediction-distribution
  alarms and label-backfill comparisons are how you give it a voice.
</Callout>
