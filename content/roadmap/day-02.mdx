## Warm-up drills

```python
import numpy as np

x = np.array([1.0, 2.0, 3.0])
y = np.array([4.0, 5.0, 6.0])

x @ y                       # dot product  = 32
np.linalg.norm(x)           # L2 norm      ≈ 3.742
x / np.linalg.norm(x)       # unit vector
np.cos(np.dot(x, y) / (np.linalg.norm(x) * np.linalg.norm(y)))  # cosine similarity
```

Every prediction you will ever debug reduces to these four lines: a dot
product **scores**, a norm **normalizes**, cosine similarity **compares
directions** regardless of magnitude. Embedding search, logits, attention —
all of it is built from this.

## Norms and distances

The norm measures a vector's length; the most common one squares, sums, and
roots:

$$\lVert \mathbf{x} \rVert_2 = \sqrt{\textstyle\sum_i x_i^2}, \qquad \lVert \mathbf{x} \rVert_1 = \textstyle\sum_i |x_i|$$

The distance between two vectors is just the norm of their difference — and
L1 versus L2 is a choice you will make again in regularization:

```python
d = y - x                        # displacement vector

np.linalg.norm(d)                # L2 (Euclidean) distance
np.linalg.norm(d, ord=1)         # L1 (Manhattan) distance
np.linalg.norm(d, ord=np.inf)    # L-infinity: the single largest jump
```

L2 punishes big misses hardest, L1 spreads its attention evenly — remember
this pairing when ridge and lasso appear later in the roadmap.

## Outer products: two vectors make a matrix

The dot product eats two vectors and returns a **scalar**. The outer product
eats two vectors and returns a **matrix** — every entry of one against every
entry of the other:

$$(\mathbf{u}\mathbf{v}^\top)_{ij} = u_i \, v_j, \qquad (m \times 1)\cdot(1 \times n) \rightarrow (m \times n)$$

```python
u = np.array([1.0, 2.0, 3.0])
v = np.array([10.0, 100.0])

np.outer(u, v)        # 3 x 2 matrix: u[i] * v[j] at every position
u[:, None] * v        # same thing via broadcasting — "column u times row v"
```

An outer product always has **rank 1**: every column is a multiple of `u`.
Keep that in mind for the callout below.

## Shape surgery: reshape and transpose

```python
a = np.arange(6)               # [0 1 2 3 4 5]
a.reshape(2, 3)                # 2 rows, 3 columns
a.reshape(2, -1)               # -1 means "infer this dimension for me"
a.reshape(2, 3).T              # transpose: shape (3, 2)
a.reshape(2, 3).ravel()        # back to flat

b = np.arange(24)
b.reshape(2, 3, 4)                        # tensors: 2 x 3 x 4
b.reshape(2, 3, 4).transpose(2, 0, 1)     # reorder the axes -> (4, 2, 3)
```

Reshape changes how you *interpret* a block of memory, not the memory itself —
total size must match, and nothing is copied unless NumPy cannot avoid it.
Transposing data to get shapes to line up is a daily move in real ML code.

## einsum: linear algebra as bookkeeping

```python
m = np.arange(6, dtype=float).reshape(2, 3)
w = np.array([0.5, 0.5, 0.5])

np.einsum("i,i->", x, y)        # dot product        -> scalar
np.einsum("ij,j->i", m, w)      # matrix @ vector    -> shape (2,)
np.einsum("ij->ji", m)          # transpose          -> shape (3, 2)
np.einsum("i,j->ij", u, v)      # outer product      -> shape (3, 2)
```

Read each string as index bookkeeping: indices that **repeat** on the left are
summed over; the indices after the arrow label the output. Every
linear-algebra operation you know fits this one pattern — attention on Day 33
is a handful of einsums, and rewriting the four lines above in that notation
once is worth an hour of reading about it.

## Eigenvectors, demonstrated

$$A\mathbf{v} = \lambda \mathbf{v}$$

An eigenvector is a direction the matrix merely **stretches** — never rotates
off its own line. Verify it, then watch repeated multiplication reveal the
dominant one:

```python
A = np.array([[4.0, 1.0],
              [2.0, 3.0]])

eigvals, eigvecs = np.linalg.eig(A)
v = eigvecs[:, 0]
lam = eigvals[0]

print(A @ v)                          # matrix times eigenvector...
print(lam * v)                        # ...equals scalar times it, up to float noise
print(np.allclose(A @ v, lam * v))    # True

# power iteration: A @ A @ ... @ A amplifies the largest eigenvalue's direction
p = np.array([1.0, 0.0])
for _ in range(20):
    p = A @ p
    p /= np.linalg.norm(p)
print(p)      # converges to [0.707, 0.707] — the leading eigenvector
```

That loop is PageRank's engine and PCA's first principal component in embryo:
**repeated multiplication by a matrix reveals its dominant direction**. The
covariance matrix's top eigenvector is exactly the direction of maximum
variance — which is what PCA computes.
