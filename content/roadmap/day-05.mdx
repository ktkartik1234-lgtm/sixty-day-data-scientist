Yesterday's gradients were deterministic. Data is not: labels flip, users
click, requests arrive in bursts. Probability is the language for that noise —
and today you get the four distributions that cover most of applied ML.

## Random variables: uncertainty with numbers attached

A **random variable** is a variable whose value comes from a chance process.
**Discrete** ones take countable values (a fraud label, a dice roll);
**continuous** ones take values from a continuum (income, temperature).

## PMF, PDF, CDF

- **PMF** (discrete): $P(X = k)$ — probability of each exact value.
- **PDF** (continuous): $f(x)$ — density, so probabilities come from areas:
  $P(a \le X \le b) = \int_a^b f(x)\,dx$.
- **CDF**: $F(x) = P(X \le x)$ — the running total; works for both kinds and
  is how you read quantiles.

## The four you will actually meet

- **Bernoulli($p$)** — one yes/no trial: did the user click, is the
  transaction fraud. $P(X=1) = p$.
- **Binomial($n$, $p$)** — $n$ independent trials: $k$ conversions from
  $n$ impressions, $k$ correct answers out of $n$ test questions.
  $$P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$$
- **Normal($\mu$, $\sigma$)** — measurement noise, residuals of a decent
  model, the *sampling distribution of means* (tomorrow).
  $$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\, e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$
- **Poisson($\lambda$)** — counts of rare events per interval: API requests
  per second, defects per batch.
  $$P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$$

## Sampling with numpy.random

```python
import numpy as np

rng = np.random.default_rng(seed=42)     # a Generator: your randomness source

flips   = rng.binomial(n=10, p=0.5, size=1000)   # 1000 runs of 10 coin flips
heights = rng.normal(loc=170, scale=8, size=1000)
clicks  = rng.poisson(lam=3.0, size=1000)        # 3 events per interval

print(flips.mean(), flips.std())       # near 5 and near sqrt(10 * 0.25)
print((heights > 186).mean())          # P(height > 2 sigma) ~ 2.3 percent
print((clicks >= 8).mean())            # P(8+ events) — a small tail
```

`loc`/`scale` are just friendly names for mean and standard deviation. Every
distribution object supports the same rhythm: sample with `size=`, then
summarize with `.mean()`, `.std()`, or a boolean mask.

<Callout kind="tip" title="Seed like a professional">
  Create one `rng = np.random.default_rng(seed)` at the top of every notebook
  and thread it through your code. Reviewers and teammates must be able to
  regenerate your exact data; a notebook whose numbers cannot be reproduced is
  not a result, it is an anecdote.
</Callout>
