Yesterday you saw what linear maps do globally. The derivative is the same
idea **locally**: the best linear approximation of a function around a point.
Today you build the object — the gradient — that will drive all of training.

## The derivative as sensitivity

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

Skip the limit and the reading stays practical: $f'(x)$ answers **"if I nudge
$x$ up a tiny bit, roughly how much does $f$ move, and in which direction?"**
When $f$ is a loss and $x$ is a model parameter, that question *is* machine
learning.

## Partials: one knob at a time

Real models have thousands of knobs. A **partial derivative**
$\frac{\partial f}{\partial w_i}$ wiggles one knob $w_i$ while freezing the
rest. Stack all of them into one vector — the **gradient**:

$$\nabla f(\mathbf{w}) = \begin{pmatrix} \frac{\partial f}{\partial w_1} \\ \vdots \\ \frac{\partial f}{\partial w_n} \end{pmatrix}$$

The gradient points in the direction of **steepest ascent**. Its negative
points downhill — remember that for Day 9, when it becomes the update rule.

## Gradient check with finite differences

You never have to trust your calculus. Perturb each input slightly and
measure:

```python
import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(size=(50, 3))
y = X @ np.array([2.0, -1.0, 0.5]) + rng.normal(scale=0.1, size=50)

def loss(w):
    r = X @ w - y
    return np.mean(r ** 2)

def analytic_grad(w):                    # what calculus (and backprop) gives
    return 2 * X.T @ (X @ w - y) / len(y)

def numeric_grad(f, w, eps=1e-6):        # what measurement gives
    g = np.zeros_like(w)
    for i in range(len(w)):
        e = np.zeros_like(w)
        e[i] = eps
        g[i] = (f(w + e) - f(w - e)) / (2 * eps)   # central difference
    return g

w = rng.normal(size=3)
print(np.allclose(analytic_grad(w), numeric_grad(loss, w), atol=1e-5))  # True
```

Agreement means your formula is right. Disagreement means a bug — this exact
check is a standard unit test inside every deep learning framework.

<Callout kind="deep" title="Slow but honest">
  Finite differences cost one function evaluation per parameter — hopeless for
  training a million-parameter model, but perfect for verifying a gradient
  formula. The central difference above has error of order $\varepsilon^2$,
  which is why `eps=1e-6` lands near machine precision. Backpropagation is
  just the chain rule applied efficiently so you never need the numeric
  version at scale.
</Callout>
