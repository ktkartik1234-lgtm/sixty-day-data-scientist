Day 6 showed that sample means wobble with a known spread. Hypothesis testing
turns that wobble into decisions: is a gap between two groups too large to
blame on chance alone?

## The courtroom: null and alternative

The **null hypothesis** $H_0$ says "nothing is going on" — same means, same
behavior. The **alternative** $H_1$ says otherwise. You never prove $H_1$;
you ask how surprising the data would be **if $H_0$ were true**. That surprise
level is the p-value: the probability of data at least this extreme under the
null. Small p means the boring world struggles to explain the data.

## A t-test on two groups

Welch's t-test compares means while letting variances differ:

$$t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}$$

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(7)
a = rng.normal(loc=50, scale=10, size=200)    # control
b = rng.normal(loc=52, scale=10, size=200)    # treatment

t_stat, p_value = stats.ttest_ind(a, b, equal_var=False)
print(f"means: {a.mean():.2f} vs {b.mean():.2f}")
print(f"t = {t_stat:.3f}, p = {p_value:.4f}")

alpha = 0.05
if p_value < alpha:
    print("reject H0: the gap is hard to explain by chance alone")
else:
    print("fail to reject H0: not enough evidence yet")
```

## Two ways to be wrong

- **Type I** — false alarm: reject a true null. Rate capped at
  $\alpha$ (usually 0.05).
- **Type II** — miss: keep a false null. Its rate is $\beta$;
  **power** $= 1 - \beta$ rises with sample size and effect size.

Every threshold is a trade: lower $\alpha$, fewer false alarms but more
misses.

## The multiple-comparisons trap

Run enough tests and a "significant" result is guaranteed:

```python
hits = 0
for _ in range(20):                     # 20 segment pairs, truly identical
    x = rng.normal(50, 10, 100)
    y = rng.normal(50, 10, 100)
    if stats.ttest_ind(x, y).pvalue < 0.05:
        hits += 1
print(hits)    # expect about 1 — a "discovery" manufactured from noise
```

Twenty tests at $\alpha = 0.05$ give a $1 - 0.95^{20} \approx 64\%$ chance of
at least one false alarm. The classic fix is Bonferroni: test each comparison
at $\alpha / k$.

<Callout kind="warn" title="P-hacking is real and it is career poison">
  Testing many segments, peeking daily until p dips below 0.05, or picking the
  outcome after seeing results manufactures significance from pure noise. A
  p-value is only meaningful if the hypothesis *and* the stopping rule were
  fixed before the data arrived. Decide the analysis first, then run it once.
</Callout>
