## From perceptron to multilayer perceptron

A perceptron is one weighted sum pushed through a nonlinearity:

$$a = \sigma(w^\top x + b)$$

One unit draws one hyperplane — it cannot even represent XOR. The fix is not a
cleverer unit but layers of ordinary ones: transform, activate, repeat.

$$h = \sigma(W_1 x + b_1), \qquad \hat{y} = W_2 h + b_2$$

That is a two-layer network (one hidden layer). With enough hidden units, such
a network can approximate any continuous function on a bounded domain — the
universal approximation theorem. The catch: "exists" is not "learnable".

## Activations: where the nonlinearity lives

Drop the $\sigma$ and everything collapses: $W_2 (W_1 x) = (W_2 W_1) x$ — one
matrix, exactly as expressive as a single layer. Two workhorses:

- **Sigmoid** $\sigma(z) = \frac{1}{1 + e^{-z}}$ squashes into $(0, 1)$; useful
  when you need a probability, but it saturates, so its gradient dies for
  large $|z|$.
- **ReLU** $\max(0, z)$ costs one comparison, never saturates for positive
  inputs, and is the default for hidden layers.

## The forward pass, in NumPy

```python
import numpy as np

def relu(z):
    return np.maximum(0.0, z)

def forward(X, W1, b1, W2, b2):
    # X has shape (n, d): one row per sample
    A1 = relu(X @ W1 + b1)      # (n, h) hidden activations
    return A1 @ W2 + b2         # (n, k) class scores, one row per sample

rng = np.random.default_rng(0)
n, d, h, k = 240, 2, 16, 2
W1 = rng.normal(size=(d, h)) * 0.5
b1 = np.zeros((1, h))
W2 = rng.normal(size=(h, k)) * 0.5
b2 = np.zeros((1, k))
scores = forward(rng.normal(size=(n, d)), W1, b1, W2, b2)
print(scores.shape)   # (240, 2)
```

Every sample flows through the same weights, and the whole batch moves as two matrix multiplications — that is the entire forward-pass concept.

## Training it on toy data

Cross-entropy loss on the scores, then gradients. Backprop is tomorrow's topic;
today we cheat with central finite differences — exact enough to learn, hopeless
at scale.

```python
def make_spirals(n_per_class=120, noise=0.2):
    xs, ys = [], []
    for c in range(2):
        r = np.linspace(0.05, 1.0, n_per_class)
        t = np.linspace(c * np.pi, (c + 1.5) * np.pi, n_per_class)
        t = t + rng.normal(size=n_per_class) * noise
        xs.append(np.column_stack([r * np.sin(t), r * np.cos(t)]))
        ys.append(np.full(n_per_class, c))
    return np.vstack(xs), np.concatenate(ys)

def loss_fn(X, y, W1, b1, W2, b2):
    z = forward(X, W1, b1, W2, b2)
    z = z - z.max(axis=1, keepdims=True)
    logp = z - np.log(np.exp(z).sum(axis=1, keepdims=True))
    return -logp[np.arange(len(y)), y].mean()

def num_grad(f, params, eps=1e-5):
    grads = []
    for p in params:
        g = np.zeros_like(p)
        it = np.nditer(p, flags=["multi_index"])
        while not it.finished:
            i = it.multi_index
            orig = p[i]
            p[i] = orig + eps; fp = f()
            p[i] = orig - eps; fm = f()
            p[i] = orig
            g[i] = (fp - fm) / (2 * eps)
            it.iternext()
        grads.append(g)
    return grads

X, y = make_spirals()
params = [W1, b1, W2, b2]
for step in range(300):
    loss = loss_fn(X, y, *params)
    grads = num_grad(lambda: loss_fn(X, y, *params), params)
    for p, g in zip(params, grads):
        p -= 0.5 * g
    if step % 100 == 0:
        acc = (forward(X, *params).argmax(axis=1) == y).mean()
        print(f"step {step:3d}  loss {loss:.4f}  train acc {acc:.2f}")
```

Accuracy climbs into the high nineties: a two-layer net bent a line into two spirals using nothing but matrix products and a max with zero.

<Callout kind="deep" title="It is matrix multiplication all the way down">
The forward pass you just wrote is the same object at every scale — frontier
models are trillions of multiplied numbers per second on hardware whose core
operation is, literally, matrix multiplication. When Day 25 moves you to PyTorch,
you are not learning new math; only who performs it, and how fast.
</Callout>
