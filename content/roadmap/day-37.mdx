## From text to points in space

An embedding model is a function $$\phi(\text{text}) \in \mathbb{R}^d$$
trained so that texts with similar meaning land near each other — typically
$d$ between 384 and 3072. After that, "find related documents" becomes
"find nearest vectors", which is linear algebra:

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("all-MiniLM-L6-v2")
emb = model.encode(["my loan approval is delayed", "credit card declined again"])
print(emb.shape)     # (2, 384): two sentences, 384 coordinates each
```

## Cosine vs dot vs L2

Three ways to compare vectors, one practical punchline:

$$\cos(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u} \cdot \mathbf{v}}{\lVert \mathbf{u} \rVert \, \lVert \mathbf{v} \rVert}, \qquad \lVert \mathbf{u} - \mathbf{v} \rVert_2^2 = 2 - 2\cos(\mathbf{u}, \mathbf{v}) \;\; \text{for unit vectors}$$

For L2-normalized embeddings — the standard — the dot product *is* the
cosine, and squared L2 distance is a decreasing function of cosine. All
three metrics rank neighbors identically. So normalize once at index time
and never worry again:

```python
import numpy as np

def normalize(X):
    return X / np.linalg.norm(X, axis=1, keepdims=True)

docs = model.encode(["refund status", "shipping delay", "refund policy for gifts"])
q = model.encode(["where is my refund"])[0]

D, qn = normalize(docs), q / np.linalg.norm(q)
print(D @ qn)                          # dot == cosine after normalization
print(np.linalg.norm(D - qn, axis=1))  # rank by L2: same order
```

## ANN indexes: the trick behind vector databases

Brute force is one matrix product, $$O(N \cdot d)$$ — perfectly fine up to
roughly a hundred thousand vectors. Past that, approximate nearest neighbor
(ANN) indexes buy speed with a little recall:

- **IVF** — k-means the corpus into lists; at query time scan only the
  `nprobe` nearest lists. Fewer probes, faster queries, more misses.
- **HNSW** — a multi-layer "skip list" graph of each point's near neighbors;
  greedy search hops from coarse layer to fine, reaching the neighborhood in
  a logarithmic-ish number of steps.

Both expose a recall/latency knob. Always measure recall against brute force
on a sample before trusting the index — you built that baseline below.

## Chunking: where RAG projects silently fail

Embedding a whole page averages every topic in it into one vector; embedding
a 40-character fragment loses the context that gives words meaning. Split on
structure (headings, paragraphs) when you can, with modest overlap so ideas
straddling a boundary survive, and store metadata alongside every chunk:

```python
def chunk(text: str, size: int = 400, overlap: int = 50) -> list[str]:
    step = size - overlap
    return [text[i:i + size] for i in range(0, len(text), step)]
```

## Build: tiny brute-force semantic search

```python
import numpy as np

class TinySearch:
    def __init__(self, model_name="all-MiniLM-L6-v2"):
        self.model = SentenceTransformer(model_name)
        self.docs, self.M = [], None

    def add(self, texts):
        self.docs.extend(texts)
        E = normalize(self.model.encode(texts))
        self.M = E if self.M is None else np.vstack([self.M, E])

    def search(self, query, k=3):
        q = normalize(self.model.encode([query]))
        scores = (self.M @ q.T).ravel()          # one matmul: cosine to all
        top = np.argsort(-scores)[:k]
        return [(self.docs[i], round(float(scores[i]), 3)) for i in top]

s = TinySearch()
s.add(["The refund window is 30 days.",
       "Shipments leave the warehouse on Mondays.",
       "Gift cards cannot be redeemed for cash."])
print(s.search("how long do I have to return something?"))
```

<Callout kind="deep" title="Normalize once, then everything is a matmul">
  After L2 normalization, cosine similarity between a query and an entire
  corpus is a single matrix-vector product — that is why vector database APIs
  feel like magic and why brute force remains a legitimate baseline at small
  scale. Keep `TinySearch` around: on Day 38 it becomes the retrieval half of
  RAG, and on Day 45 the arbiter of whether an ANN index is even needed.
</Callout>
