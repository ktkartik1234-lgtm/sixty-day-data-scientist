## Choose your battlefield

Two tracks; pick by interest and hardware:

- **Images** — CIFAR-10 or FashionMNIST with your own CNN (Day 28) plus a
  fine-tuned ResNet (Day 29).
- **Text** — a small Hugging Face dataset (Day 32's emotion data, or ag_news)
  fine-tuned on DistilBERT.

Both fit in an evening on CPU or a free GPU, and the engineering shape is
identical — which is the point: pipeline, model, train, evaluate, save,
report.

## The pipeline

```python
from datasets import load_dataset
from transformers import AutoTokenizer

raw = load_dataset("dair-ai/emotion")        # train, validation, test
tok = AutoTokenizer.from_pretrained("distilbert/distilbert-base-uncased")
enc = raw.map(lambda b: tok(b["text"], truncation=True), batched=True)
labels = raw["train"].features["label"].names
print(len(labels), "classes:", labels)
```

Freeze the test split now and do not look at it again until the final
evaluation. Day 27's validation curves are for decisions; the test set is for
the truth.

## Model, train, evaluate

```python
from transformers import AutoModelForSequenceClassification, Trainer, TrainingArguments

model = AutoModelForSequenceClassification.from_pretrained(
    "distilbert/distilbert-base-uncased", num_labels=len(labels)
)
args = TrainingArguments(
    output_dir="artifacts/day34",
    learning_rate=2e-5,
    per_device_train_batch_size=16,
    num_train_epochs=3,
    eval_strategy="epoch",
    save_strategy="epoch",
    load_best_model_at_end=True,
)
trainer = Trainer(model=model, args=args,
                  train_dataset=enc["train"], eval_dataset=enc["validation"])
trainer.train()
trainer.evaluate(enc["test"])      # the test set: touched exactly once
```

Honest evaluation is more than one number: overall accuracy, a confusion
matrix, per-class recall — the classes the model silently fails on are the
story. And compare against a baseline that is not deep learning: Phase 2's
logistic regression on TF-IDF features takes minutes and grounds the claim
that the neural model earns its keep.

## Save artifacts, write the report

```python
import json

trainer.save_model("artifacts/day34/final")
tok.save_pretrained("artifacts/day34/final")
with open("artifacts/day34/final/metrics.json", "w") as f:
    json.dump(trainer.evaluate(enc["test"]), f, indent=2)
```

`save_model` writes portable weights plus config, so a fresh `from_pretrained`
reloads the model anywhere. Then the five bullets — the actual deliverable:

1. **Task** — classify short texts into six emotions, in one sentence.
2. **Data** — source, size, splits, class balance, and one caveat.
3. **Model** — DistilBERT body with a fresh head, and why that choice.
4. **Result** — test accuracy and per-class recall versus the non-neural
   baseline.
5. **Caveats and next step** — the honest limits, plus the single
   highest-value experiment you did not run.

<Callout kind="warn" title="The test set is sacred">
Every metric you peek at during development quietly becomes a training
signal: you pick checkpoints, thresholds and even ideas because of what you
saw. That is Phase 2's leakage wearing a GPU. Decide on validation, touch the
test set once, and report the number you saw first — not the best number you
saw.
</Callout>
