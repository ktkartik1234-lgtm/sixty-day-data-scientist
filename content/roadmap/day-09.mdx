Day 4 taught you to compute gradients and verify them numerically; Day 8 made
you appropriately skeptical of lucky results. Today the gradient finally does
work: it becomes the engine that trains every model in the next 50 days.

## The update rule

$$\mathbf{w}_{t+1} = \mathbf{w}_t - \eta\, \nabla_\mathbf{w} L(\mathbf{w}_t)$$

Compute the gradient of the loss, step a small amount $\eta$ (the **learning
rate**) **against** it — downhill — and repeat. That is all training is.

## Batch gradient descent for linear regression

With MSE loss, $L = \frac{1}{2n}\lVert X\mathbf{w} - \mathbf{y}\rVert^2$, the
gradient is one vectorized line — Day 7 paying dividends:

```python
import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(0, 2, size=(200, 2))
true_w = np.array([3.0, -2.0])
y = X @ true_w + 1.0 + rng.normal(0, 0.5, size=200)

Xb = np.column_stack([X, np.ones(len(X))])     # add a bias column

def loss(w):
    r = Xb @ w - y
    return (r @ r) / (2 * len(y))

w = np.zeros(3)
eta = 0.05
history = []
for step in range(300):
    grad = Xb.T @ (Xb @ w - y) / len(y)        # the entire backward pass
    w -= eta * grad
    history.append(loss(w))

print(w)                    # close to [3, -2, 1]
print(history[0], history[-1])
```

## The learning-rate experiment

For a quadratic loss the surface is a bowl with steepest curvature
$L_{\max}$ (the largest eigenvalue of $X^\top X / n$). Convergence needs
$\eta < 2 / L_{\max}$ — cross that line and each step *amplifies* the error:

```python
for eta in [0.001, 0.05, 0.5, 0.9]:
    w = np.zeros(3)
    for step in range(300):
        w -= eta * Xb.T @ (Xb @ w - y) / len(y)
    print(f"eta={eta:6.3f}  final loss={loss(w)}")
```

Watch the printed losses: 0.001 barely moves, 0.05 converges cleanly, and the
last two explode to enormous values or NaN. **NaN means you stepped past the
cliff** — it is a diagnosis, not a mystery.

## Batch vs stochastic

Full-batch uses all 200 rows per step: exact gradient, expensive per step.
**Stochastic** gradient descent uses one sample (or a small batch) at a time:

```python
w = np.zeros(3)
for epoch in range(20):
    order = rng.permutation(len(y))            # shuffle each epoch
    for i in order:
        xi, yi = Xb[i], y[i]
        w -= 0.01 * xi * (xi @ w - yi)         # one-sample gradient: noisy, cheap
```

The path is jittery, but each step is nearly free — on millions of rows this
is the only affordable option, and the noise even helps escape sharp, brittle
regions of the loss surface (more on that in the optimization track).

<Callout kind="deep" title="Why this demo is deterministic, not lucky">
  MSE's loss surface is a perfect paraboloid, so gradient descent on it has an
  exact stability bound, $\eta < 2/L_{\max}$ — divergence at $\eta = 0.9$ is
  guaranteed mathematics, not bad luck. Real neural nets bend that picture,
  but the intuition carries: the learning rate is the single most
  consequential knob you will turn all challenge.
</Callout>
