Yesterday's from-scratch CNN earned roughly 70 percent on CIFAR-10 after ten
epochs. A [ResNet](/papers) pretrained on ImageNet clears 95 percent with a
few minutes of head-only training — because its features already exist.

## Why pretrained features transfer

Early conv layers learn edges, color blobs and textures — the visual
vocabulary every image task shares. The [ResNet](/papers) checkpoints trained
on 1.2 million ImageNet images, and ViT-style models from the
[vision transformer](/papers) lineage on hundreds of millions more, encode
that vocabulary in their weights. Your 500-image problem does not need to
relearn edges; it needs a small classifier on top of a frozen visual
dictionary. This is the deepest form of the reuse this course keeps finding:
the same idea that made kernels shared across locations now makes entire
networks shared across tasks.

## Replace the head

```python
import torch.nn as nn
from torchvision import models

model = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1)
model.fc = nn.Linear(model.fc.in_features, 10)   # swap the 1000-way head for yours
```

The same move works for vision transformers in two lines via transformers:
load a `ViTForImageClassification` checkpoint, replace its classifier head.
The rule never changes: new task, new head; the body is a feature extractor.

## Freeze, then fine-tune

```python
for p in model.parameters():
    p.requires_grad = False               # freeze the backbone
model.fc = nn.Linear(model.fc.in_features, 10)
# the optimizer now sees only the head's ~5k parameters

# optional, data permitting — unfreeze the last block only:
for p in model.layer4.parameters():
    p.requires_grad = True
```

Decision rule: little data, or a domain far from natural photos — freeze more,
train the head longer, and use a small learning rate (1e-4 or less) when you
do unfreeze. Plenty of similar-domain data — fine-tune everything with a low
learning rate from the start. One small-data gotcha: with tiny batches,
BatchNorm's running statistics get corrupted, so keep BN layers frozen or in
eval mode even while fine-tuning the rest.

## Augmentation for small data

Day 27's augmentation earns its keep here more than anywhere: every augmented
view is a fresh, free sample for the head you are training.

```python
from torchvision import transforms

train_tf = transforms.Compose([
    transforms.RandomResizedCrop(224),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225]),
])
```

Those exact mean and standard deviation values are the ImageNet statistics the
pretrained model was fed — copy them, never invent them.

<Callout kind="tip" title="Borrow the preprocessing, not just the weights">
The pretrained model expects inputs normalized with specific statistics.
Skipping that normalization raises no error — your features are just quietly
worse and you will blame the wrong thing. Whenever you adopt pretrained
weights, adopt the exact preprocessing pipeline they were trained with.
</Callout>
