In the last lesson a matrix was a grid of numbers. Give it a job: a matrix
$A \in \mathbb{R}^{m \times n}$ is a machine that takes an $n$-dimensional
vector in and returns an $m$-dimensional vector out. Every linear model,
embedding layer, and attention head is this machine in disguise.

## The matrix-vector product is a transformation

The one identity to memorize: $A\mathbf{x}$ is a weighted mix of the columns
of $A$.

$$A\mathbf{x} = x_1 \mathbf{a}_1 + x_2 \mathbf{a}_2 + \dots + x_n \mathbf{a}_n = \sum_{j=1}^{n} x_j\, \mathbf{a}_j$$

The entries of $\mathbf{x}$ decide how much of each column survives. Two
properties come free. The origin stays put ($A\mathbf{0} = \mathbf{0}$), and
the machine respects combinations:

$$A(\alpha \mathbf{u} + \beta \mathbf{v}) = \alpha\, A\mathbf{u} + \beta\, A\mathbf{v}$$

That equation **is** the definition of a linear transformation. Grid lines
stay parallel and evenly spaced; the allowed moves are shears, rotations,
reflections, and scalings — nothing that bends or curves space.

## Composition is matrix multiplication

Apply a transformation $B$ to $\mathbf{x}$, then apply another one $A$ to the
result. The combined map must satisfy:

$$(AB)\mathbf{x} = A(B\mathbf{x})$$

so a single matrix $AB$ does both jobs at once, and it is exactly the matrix
product. Mind the order: $AB$ means **apply $B$ first**. Composition is
associative but not commutative — rotate-then-scale lands somewhere different
from scale-then-rotate, which is why $AB \neq BA$ in general.

<Callout kind="deep" title="A neural layer is a transformation">
  A dense layer computes $\mathbf{h} = \phi(X\mathbf{w} + \mathbf{b})$: every
  input row is pushed through the same linear map, then bent by a nonlinearity
  $\phi$. Stacking layers is composing transformations, and backpropagation is
  the same story in reverse — multiply by each transformation's transpose on
  the way back down.
</Callout>

## Identity and inverse

The identity matrix $I$ is the do-nothing transformation, $I\mathbf{x} =
\mathbf{x}$. When a transformation can be undone, its inverse satisfies:

$$A^{-1}A = AA^{-1} = I \qquad \text{so} \qquad A\mathbf{x} = \mathbf{b} \iff \mathbf{x} = A^{-1}\mathbf{b}$$

Undoing only works if $A$ neither flattens space nor merges two points into
one: if $A\mathbf{u} = A\mathbf{v}$ with distinct $\mathbf{u}$ and $\mathbf{v}$,
information is destroyed and no inverse can exist. In practice you rarely form
$A^{-1}$ explicitly — solvers such as `np.linalg.solve` factor $A$ instead,
which is faster and numerically safer.

## Rank: how much information survives

The rank of $A$ is the dimension of the space its columns span — the dimension
of everything the transformation can output. For $A \in \mathbb{R}^{m \times n}$:

- Full column rank ($\text{rank} = n$): no input direction is crushed, the map
  is injective, and square systems have unique solutions.
- Deficient rank ($\text{rank}$ less than $n$): at least one direction is
  flattened to $\mathbf{0}$; the matrix is singular.

A projection onto a single line has rank 1: a whole plane squeezed onto one
direction. Rank is thus a measure of preserved information, and it resurfaces
everywhere — is $X^\top X$ invertible in least squares? Which features are
linearly redundant? Why do low-rank adapters fine-tune LLMs so cheaply?

## Worked problem

<Callout kind="info" title="Problem">
  Let $R = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}$ (rotate 90 degrees
  counterclockwise) and $S = \begin{bmatrix} 2 & 0 \\ 0 & 3 \end{bmatrix}$
  (stretch by 2 horizontally and 3 vertically). Compose $M = RS$, apply it to
  $\mathbf{v} = \begin{bmatrix} 1 \\ 1 \end{bmatrix}$, and confirm that doing
  it in one step matches doing it in two. Which transformation acts first?
</Callout>

<Solution>
  Multiply the matrices, pairing rows of $R$ with columns of $S$:

  $$M = RS = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}\begin{bmatrix} 2 & 0 \\ 0 & 3 \end{bmatrix} = \begin{bmatrix} 0 & -3 \\ 2 & 0 \end{bmatrix}$$

  For example the top-right entry is $(0)(0) + (-1)(3) = -3$. Now apply the
  composition to $\mathbf{v}$:

  $$M\mathbf{v} = \begin{bmatrix} 0 & -3 \\ 2 & 0 \end{bmatrix}\begin{bmatrix} 1 \\ 1 \end{bmatrix} = \begin{bmatrix} -3 \\ 2 \end{bmatrix}$$

  Because $M = RS$ means $S$ acts first, verify stepwise:
  $S\mathbf{v} = \begin{bmatrix} 2 \\ 3 \end{bmatrix}$, then

  $$R(S\mathbf{v}) = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}\begin{bmatrix} 2 \\ 3 \end{bmatrix} = \begin{bmatrix} -3 \\ 2 \end{bmatrix}$$

  — identical, as it must be. The stretch happens first, then the rotation.
  NumPy agrees:

  ```python
  import numpy as np

  R = np.array([[0.0, -1.0], [1.0, 0.0]])   # 90-degree rotation
  S = np.array([[2.0, 0.0], [0.0, 3.0]])    # stretch x by 2, y by 3
  v = np.array([1.0, 1.0])

  M = R @ S
  print(M @ v)          # [-3.  2.]
  print(R @ (S @ v))    # [-3.  2.]  — same vector, B applied first
  ```
</Solution>
