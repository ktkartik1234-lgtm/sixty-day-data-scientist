Flip a fair coin: the outcome is maximally unpredictable. Flip a coin that
lands heads 99% of the time: you already know the answer most of the time —
there is little *uncertainty* to resolve. Entropy turns that intuition into a
number.

## Surprise and information

Shannon defined the information (or "surprisal") of an outcome with
probability $p$ as:

$$I(x) = \log_2 \frac{1}{p(x)} = -\log_2 p(x)$$

Rare events are surprising (high information); certain events are not
(information zero). Measured in **bits** when the log base is 2: learning a
fair coin flip is worth exactly 1 bit.

## Entropy: average surprise

The entropy of a distribution is the expected surprisal over its outcomes:

$$H(X) = -\sum_{x} p(x) \log_2 p(x)$$

Properties worth internalizing:

- $H = 0$ when the outcome is certain (no uncertainty).
- For a binary variable, $H$ is maximal at $p = 0.5$ — exactly 1 bit.
- For $n$ equally likely outcomes, $H = \log_2 n$.
- Entropy never negative; it depends only on the distribution, not on the
  labels.

<Callout kind="deep" title="Why decision trees care">
  When a decision tree picks a split, it is choosing the question that
  maximally reduces entropy — the information gain is literally the entropy
  drop from knowing the split outcome (Day 17).
</Callout>

## In code

```python
import numpy as np

def entropy(p):
    p = np.asarray(p)
    p = p[p > 0]                      # 0 log 0 = 0 by convention
    return -np.sum(p * np.log2(p))

entropy([0.5, 0.5])     # 1.0   — fair coin, maximum uncertainty
entropy([0.9, 0.1])     # 0.469 — biased coin, mostly predictable
entropy([1.0, 0.0])     # 0.0   — certain outcome
```

## Worked problem

<Callout kind="info" title="Problem">
  A dataset has two classes: 90% negative, 10% positive. Compute the entropy
  of the class distribution, and compare it with a balanced 50/50 dataset of
  the same size.
</Callout>

<Solution>
  $$H = -(0.9 \log_2 0.9 + 0.1 \log_2 0.1) = -(0.9 \times (-0.152) + 0.1 \times (-3.322)) \approx 0.469 \text{ bits}$$

  The balanced dataset has $H = 1$ bit. The imbalanced one carries less than
  half the uncertainty per example — which is exactly why a lazy classifier
  that always predicts "negative" is hard to beat on accuracy (Day 22): the
  label alone is already 0.469 bits predictable.
</Solution>
