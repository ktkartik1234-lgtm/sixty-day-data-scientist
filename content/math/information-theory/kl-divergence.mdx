You have a true distribution $P$ (the data) and a model distribution $Q$ (your
approximation). How wrong is $Q$? The Kullback–Leibler divergence gives the
answer, and training a model is, at heart, making that number small.

## Definition

$$D_{KL}(P \,\|\, Q) = \sum_{x} p(x) \log_2 \frac{p(x)}{q(x)}$$

Read it as: the average extra bits you spend when encoding events from $P$
using a code optimized for $Q$. If $Q = P$ everywhere, the divergence is zero.
The more $Q$ assigns small probability to things $P$ does often, the larger it
grows.

## Three properties that matter

1. **It is not a distance.** $D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$ — the
   asymmetry is a feature, not a bug.
2. **Non-negative**, and zero only when $P = Q$ (Gibbs' inequality).
3. **It penalizes confident wrongness hardest.** If $P$ puts mass where $Q$
   puts almost none, the term $p \log (p/q)$ explodes.

<Callout kind="deep" title="Forward vs reverse KL">
  Minimizing $D_{KL}(P \| Q)$ (forward) forces $Q$ to cover every place $P$
  has mass — $Q$ spreads out. Minimizing $D_{KL}(Q \| P)$ (reverse) forces $Q$
  to never place mass where $P$ has none — $Q$ narrows and may miss modes.
  Variational inference (the variational autoencoder's loss) and policy
  optimization differ largely by which direction they choose.
</Callout>

## Where you already use it

- **Maximum likelihood training** of a model $q_\theta$ on data from $p$ is
  equivalent to minimizing $D_{KL}(p \,\|\, q_\theta)$ — see the cross-entropy
  lesson for the algebra.
- **Knowledge distillation**: a small student model matches a large teacher's
  output distribution by minimizing KL between them.
- **Regularization**: variational autoencoders regularize the latent code
  toward a prior with a KL term; PPO clips policy updates to keep the new
  policy's KL from the old one small.

## In code

```python
import numpy as np

def kl_divergence(p, q):
    p, q = np.asarray(p), np.asarray(q)
    mask = p > 0
    return np.sum(p[mask] * np.log2(p[mask] / q[mask]))

kl_divergence([0.5, 0.5], [0.9, 0.1])   # ≈ 0.737 bits
kl_divergence([0.9, 0.1], [0.5, 0.5])   # ≈ 0.531 bits — asymmetric!
```

## Worked problem

<Callout kind="info" title="Problem">
  A fair coin $P = (0.5, 0.5)$ is modeled by a biased model
  $Q = (0.9, 0.1)$. Compute $D_{KL}(P \| Q)$ and $D_{KL}(Q \| P)$ and confirm
  they differ.
</Callout>

<Solution>
  Forward: $$D_{KL}(P \| Q) = 0.5 \log_2 \frac{0.5}{0.9} + 0.5 \log_2 \frac{0.5}{0.1} = 0.5(-0.848) + 0.5(2.322) \approx 0.737 \text{ bits}$$

  Reverse: $$D_{KL}(Q \| P) = 0.9 \log_2 \frac{0.9}{0.5} + 0.1 \log_2 \frac{0.1}{0.5} = 0.9(0.848) + 0.1(-2.322) \approx 0.531 \text{ bits}$$

  Same two distributions, different numbers — KL is directional. The forward
  direction punishes the model harder for claiming tails is rare (0.1) when
  truth says 0.5, because that is where the model would waste the most bits.
</Solution>
